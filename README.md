# ApexPlanet Internship - Task 1

## Task
Basics of Web Development (Days 1-9)

## Requirements Completed
1. Created a simple webpage using HTML.
2. Styled the webpage using CSS.
3. Added JavaScript interactivity with a button that displays an alert.

## Files
- `index.html` - webpage structure
- `style.css` - styling and responsive layout
- `script.js` - button interaction
- `images/web-development.svg` - local webpage illustration

## How to Run
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file and select **Open with Live Server** if the Live Server extension is installed.
4. Or simply double-click `index.html` to open it in a browser.
5. Click the **Click Me** button to test JavaScript.
